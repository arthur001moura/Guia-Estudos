#  Guia-Estudos

Um cantinho onde vou juntando mini guias, anotações e coisas que vou aprendendo durante meus estudos.

A ideia é simples: aprendi alguma coisa que achei útil? Vem pra cá. 

Não é um material acadêmico e nem pretende ser uma documentação oficial.
São guias rápidos baseados no que estou estudando e, principalmente, no que funcionou pra mim.

##  O que tem por aqui por enquanto?

-  Git & GitHub
-  SQL
-  Outros assuntos que vão parecer pelo caminho

## 🚧 sempre em construção

Esse repositório vai sendo atualizado conforme eu avanço nos estudos.

Então provavelmente vai ter coisa simples, coisa que eu ainda estou aprendendo e algumas anotações que podem mudar com o tempo ou que estão erradas.

---

### ⚠️ Observação

Se encontrar alguma coisa errada,é sua obrigação apontar, sempre bom aprender mais!
